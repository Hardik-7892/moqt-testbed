## 5.2 Media pipeline (why 320×240 30 fps 2 s GOP fMP4)

One `ffmpeg lavfi` source generates everything; `harness/runner.py:843` bind-mounts `TESTDATA_DIR` read-only as `/data/{media}`; `sub_output.file /output/{stream} vs /output/{stream}.flv` isolates per-impl paths (B17).

- `Makefile:219-227 sample.mp4`: `color=red:320×240:30:d=10` + dual `drawtext` countdown + ms, `-an libx264 yuv420p -g 30 -force_key_frames gte(t,1) -t 10 -movflags empty_moov+frag_keyframe+separate_moof`, `ffprobe 10.000000s`. For `test-all-sample` fast iteration.
- `Makefile:229-237 sample_120s.mp4`: clone `d=120 g 60 force_key gte(t,2) -t 120`. `120→0` so late-join skip is visually auditable. Tiny bitrate avoids B25 scale confound while stressing `bw:5 queue:1000` (I16).
- Why 2 s (D2.2, `decisions.md:38-45`): MoQ `group=1 GOP, object=1 moof/mdat` (`verify.py:217-239`). `g 30 (1 s)` → 120 groups vs DASH 60×2 s segments — unfair request count + late-join math (`5 s→5 vs 2` groups). `g 60@30fps + 2 s` → ~60 groups ~2 s; moxygen inherits via `-c copy`; imquic forwards same groups.
- fMP4 (`verify.py:217-253`): `expected_objects()=init + one per moof/mdat`, excl. `mfra/free`; `expected_media_bytes()=data[:last_mdat_end]`. Non-fragmented falls back single object. Makes `expected_bytes/sha256/per_object` comparable MoQ vs DASH.
- FLV (`Makefile:239-242,261-264`): `ffmpeg -i mp4 -c copy flv || libx264 -an`. D7: FLV `h264/AAC-LC` MoQMI, `playable copy`, approximate.
- MPD (`Makefile:244-256,266-270`): `MP4Box -dash 2000 -frag 2000 -profile live` else `ffmpeg -f dash -seg_duration 2` else `gen-lldash-mpd.py`. `sample.mpd` prefixed `sample10-*` so 120 s `chunk-stream0-*` never collides (D11). `segment=fragment=2 s`: one GET/2 s ≈ one MoQ object/moof, comparable concurrency under loss/bw.
- BBB: `bbb.mp4 via fetch-bbb.sh` (Blender M4V CC-BY, `testdata/README.md`), `bbb-video.mp4 via fetch-bbb-video.sh` (video-only), `bbb.flv via fetch-flv.sh`. Observed `testdata/`: `sample.mp4/flv/mpd`, `sample_120s.mp4/flv/mpd`, `sample_1seg.mp4` (B45 honest TP), `sample10-* (5×2 s)`, `chunk-stream0-* (60×2 s)`, `bbb*`, `dash/` staging.

## 5.4 Fair-comparison rules D2–D14 (cite these in Ch4 Table 4.1 + Ch6 Fig 6.7)

## 5.5 Known media limits
